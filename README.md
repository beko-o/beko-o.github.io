# Bekzat Mustafa — portfolio landing page

An updated, responsive one-page portfolio for GitHub Pages. No build tools, npm packages or backend required.

## Files
- `index.html` — all HTML, CSS, and JavaScript for the site.
- `Bekzat_Mustafa_CV.pdf` — downloadable CV; linked from the hero and footer.

## Publish at https://beko-o.github.io/
1. Open the `beko-o/beko-o.github.io` GitHub repository.
2. Back up its existing `index.html` before replacing it.
3. Upload the new `index.html` and `Bekzat_Mustafa_CV.pdf` to the **repository root** (main branch if that is the Pages source).
4. Commit the changes and check GitHub Pages settings if needed (`Settings → Pages`).
5. Hard-refresh the public URL after GitHub Pages deploys the change.

## Before publication
- Confirm you are comfortable publishing the supplied CV, which contains your phone number.
- Confirm project statistics and descriptions remain accurate and publicly shareable.
- Optional: add verified links to other projects, a photo, or a `og:image` for social sharing.
- If you edit the PDF, keep the filename unchanged or update the two links to it in `index.html`.

## Notes
- The site is in English for international recruiters.
- Theme preference is saved locally in the browser; otherwise the system preference is used.
- It uses Google Fonts with system fallback. Everything else is dependency-free.
- Small screens and reduced-motion accessibility preferences are supported.
